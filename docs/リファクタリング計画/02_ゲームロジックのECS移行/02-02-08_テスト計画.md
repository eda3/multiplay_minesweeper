# ボードロジックをシステムへ移行 - テスト計画

最終更新日: 2025年4月5日

## テスト戦略の概要

ボードロジックのECSへの移行に伴い、包括的なテスト戦略を実装して、機能的な同等性と改善されたパフォーマンスを保証します。テスト戦略は以下の原則に基づいています：

- 広範囲なユニットテストによる各コンポーネントとシステムの検証
- 統合テストによるシステム間の相互作用の検証
- エンドツーエンドテストによる全体的な機能の検証
- パフォーマンステストによる最適化の検証
- 既存実装と新実装の比較テスト

## テストレベル

```rust
#[cfg(test)]
mod board_init_system_tests {
    use super::*;
    use crate::ecs::{World, ResourceManager};
    
    #[test]
    fn test_board_init_creates_entities() {
        let mut world = World::new();
        let mut resources = ResourceManager::new();
        
        // リソースの設定
        let config = BoardConfigResource::new(5, 5, 5, Difficulty::Custom);
        resources.set(config);
        
        // システムの実行
        let system = BoardInitSystem;
        system.update(&mut world, &mut resources).unwrap();
        
        // 結果の検証
        let board_state = resources.get::<BoardStateResource>().unwrap();
        assert_eq!(board_state.cell_entities.len(), 5);
        assert_eq!(board_state.cell_entities[0].len(), 5);
        
        // エンティティの検証
        for row in 0..5 {
            for col in 0..5 {
                let entity_id = board_state.get_cell_at(row, col).unwrap();
                
                // 各エンティティが必要なコンポーネントを持っているか確認
                assert!(world.has_component::<GridPositionComponent>(entity_id));
                assert!(world.has_component::<CellStateComponent>(entity_id));
                assert!(world.has_component::<CellContentComponent>(entity_id));
                
                // GridPositionが正しいか確認
                let grid_pos = world.get_component::<GridPositionComponent>(entity_id).unwrap();
                assert_eq!(grid_pos.row, row);
                assert_eq!(grid_pos.col, col);
            }
        }
    }
}
```

### 2. 統合テスト

複数のシステムが連携して動作することを検証します。

```rust
#[cfg(test)]
mod board_systems_integration_tests {
    use super::*;
    use crate::ecs::{World, ResourceManager, SystemRegistry};
    
    fn setup_test_environment() -> (World, ResourceManager, SystemRegistry) {
        let mut world = World::new();
        let mut resources = ResourceManager::new();
        let mut registry = SystemRegistry::new();
        
        // システムの登録
        registry.register(Box::new(BoardInitSystem))
            .phase(SystemPhase::Initialization);
        registry.register(Box::new(MinePlacementSystem))
            .phase(SystemPhase::Update);
        registry.register(Box::new(CellRevealSystem))
            .phase(SystemPhase::Update);
        registry.register(Box::new(FlagToggleSystem))
            .phase(SystemPhase::Update);
        registry.register(Box::new(WinConditionSystem))
            .phase(SystemPhase::PostUpdate);
        
        // リソースの設定
        resources.set(BoardConfigResource::new(5, 5, 5, Difficulty::Custom));
        resources.set(EventQueue::new());
        resources.set(ClickEventQueue::new());
        
        (world, resources, registry)
    }
    
    #[test]
    fn test_init_and_reveal_integration() {
        let (mut world, mut resources, mut registry) = setup_test_environment();
        
        // 初期化フェーズの実行
        registry.execute_phase(&mut world, &mut resources, SystemPhase::Initialization).unwrap();
        
        // ボードが正しく初期化されたか確認
        let board_state = resources.get::<BoardStateResource>().unwrap();
        assert_eq!(board_state.cell_entities.len(), 5);
        
        // クリックイベントのシミュレーション
        let mut click_events = resources.get_mut::<ClickEventQueue>().unwrap();
        click_events.events.push(ClickEvent {
            grid_position: GridPosition { row: 2, col: 2 },
            button: MouseButton::Left,
        });
        
        // 更新フェーズの実行
        registry.execute_phase(&mut world, &mut resources, SystemPhase::Update).unwrap();
        
        // 初回クリック後の状態確認
        let board_state = resources.get::<BoardStateResource>().unwrap();
        assert!(!board_state.is_first_click);
        
        // 地雷が配置されたか確認
        let mut mine_count = 0;
        for row in 0..5 {
            for col in 0..5 {
                if let Some(entity_id) = board_state.get_cell_at(row, col) {
                    if let Ok(content) = world.get_component::<CellContentComponent>(entity_id) {
                        if content.is_mine() {
                            mine_count += 1;
                        }
                    }
                }
            }
        }
        assert_eq!(mine_count, 5); // 設定した地雷数
    }
    
    #[test]
    fn test_reveal_and_win_condition_integration() {
        let (mut world, mut resources, mut registry) = setup_test_environment();
        
        // 特殊なテスト用ボード設定（地雷1つのみ）
        resources.set(BoardConfigResource::new(2, 2, 1, Difficulty::Custom));
        
        // 初期化フェーズの実行
        registry.execute_phase(&mut world, &mut resources, SystemPhase::Initialization).unwrap();
        
        // 初回クリックのシミュレーション
        let mut click_events = resources.get_mut::<ClickEventQueue>().unwrap();
        click_events.events.push(ClickEvent {
            grid_position: GridPosition { row: 0, col: 0 },
            button: MouseButton::Left,
        });
        
        // 更新フェーズの実行（初回クリックと地雷配置）
        registry.execute_phase(&mut world, &mut resources, SystemPhase::Update).unwrap();
        
        // 地雷の位置を特定（初回クリック位置以外）
        let board_state = resources.get::<BoardStateResource>().unwrap();
        let mut mine_position = None;
        for row in 0..2 {
            for col in 0..2 {
                if row == 0 && col == 0 {
                    continue; // 初回クリック位置はスキップ
                }
                
                if let Some(entity_id) = board_state.get_cell_at(row, col) {
                    if let Ok(content) = world.get_component::<CellContentComponent>(entity_id) {
                        if content.is_mine() {
                            mine_position = Some((row, col));
                            break;
                        }
                    }
                }
            }
            if mine_position.is_some() {
                break;
            }
        }
        
        // クリックイベントのクリア
        click_events.events.clear();
        
        // 残りの非地雷セルをクリック
        for row in 0..2 {
            for col in 0..2 {
                if row == 0 && col == 0 {
                    continue; // 既にクリック済み
                }
                
                if Some((row, col)) == mine_position {
                    continue; // 地雷はクリックしない
                }
                
                click_events.events.push(ClickEvent {
                    grid_position: GridPosition { row, col },
                    button: MouseButton::Left,
                });
                
                // 更新フェーズの実行
                registry.execute_phase(&mut world, &mut resources, SystemPhase::Update).unwrap();
            }
        }
        
        // ポスト更新フェーズの実行（勝利条件チェック）
        registry.execute_phase(&mut world, &mut resources, SystemPhase::PostUpdate).unwrap();
        
        // 勝利状態になったか確認
        let board_state = resources.get::<BoardStateResource>().unwrap();
        assert!(matches!(board_state.game_state, BoardGameState::Won));
    }
}
```

### 3. エンドツーエンドテスト

ユーザーの視点からの一連の操作をシミュレーションします。

```rust
#[cfg(test)]
mod board_e2e_tests {
    use super::*;
    use crate::game::{Game, GameConfig, CellPosition};
    
    #[test]
    fn test_complete_game_flow() {
        // フィーチャーフラグの有効化
        crate::config::set_feature_enabled("use_ecs_board", true);
        
        // ゲーム設定（固定シード値で再現性を確保）
        let config = GameConfig {
            board_width: 5,
            board_height: 5,
            mine_count: 5,
            random_seed: Some(12345), // 再現性のための固定シード
            difficulty: Difficulty::Custom,
        };
        
        // ゲームの作成
        let mut game = Game::new(config);
        
        // 初回クリック（常に安全）
        let result = game.reveal_cell(CellPosition::new(2, 2));
        assert!(result.is_ok());
        
        // ゲームが進行中であることを確認
        assert!(game.is_in_progress());
        
        // フラグを立てる
        for &(row, col) in &[(0, 0), (0, 4), (4, 0), (4, 4), (2, 3)] {
            let result = game.toggle_flag(CellPosition::new(row, col));
            assert!(result.is_ok());
        }
        
        // フラグ数を確認
        assert_eq!(game.flag_count(), 5);
        
        // 残りのセルを公開
        for row in 0..5 {
            for col in 0..5 {
                // フラグ付きセルはスキップ
                if (row == 0 && col == 0) || (row == 0 && col == 4) || 
                   (row == 4 && col == 0) || (row == 4 && col == 4) || 
                   (row == 2 && col == 3) {
                    continue;
                }
                
                // 既に公開されたセルもスキップ
                if game.is_cell_revealed(CellPosition::new(row, col)) {
                    continue;
                }
                
                let result = game.reveal_cell(CellPosition::new(row, col));
                
                // 地雷に当たってゲームオーバーになった場合、それ以上のセルは公開しない
                if game.is_game_over() {
                    break;
                }
                
                assert!(result.is_ok());
            }
            
            if game.is_game_over() {
                break;
            }
        }
        
        // ゲームが終了していることを確認
        assert!(game.is_game_over());
        
        // プレイ時間が記録されていることを確認
        assert!(game.play_time() > 0.0);
    }
}
```

### 4. パフォーマンステスト

新実装のパフォーマンスを検証します。

```rust
#[cfg(test)]
mod board_performance_tests {
    use super::*;
    use std::time::{Instant, Duration};
    use test::Bencher;
    
    // 既存実装のパフォーマンス測定
    #[bench]
    fn bench_legacy_board_init(b: &mut Bencher) {
        crate::config::set_feature_enabled("use_ecs_board", false);
        
        b.iter(|| {
            let board = Board::new(30, 16, 99); // エキスパート難易度
            assert_eq!(board.width(), 30);
            assert_eq!(board.height(), 16);
        });
    }
    
    // 新実装のパフォーマンス測定
    #[bench]
    fn bench_ecs_board_init(b: &mut Bencher) {
        crate::config::set_feature_enabled("use_ecs_board", true);
        
        b.iter(|| {
            let board = Board::new(30, 16, 99); // エキスパート難易度
            assert_eq!(board.width(), 30);
            assert_eq!(board.height(), 16);
        });
    }
    
    // 連鎖公開のパフォーマンス比較
    #[test]
    fn compare_chain_reveal_performance() {
        // 既存実装のセットアップ
        crate::config::set_feature_enabled("use_ecs_board", false);
        let mut legacy_board = Board::new(30, 16, 99);
        legacy_board.reveal_cell(0, 0); // 初回クリック
        
        // 既存実装のパフォーマンス測定
        let start = Instant::now();
        for _ in 0..100 {
            let _ = legacy_board.clone().reveal_cell(15, 8); // 中央付近でクリック
        }
        let legacy_time = start.elapsed();
        
        // 新実装のセットアップ
        crate::config::set_feature_enabled("use_ecs_board", true);
        let mut ecs_board = Board::new(30, 16, 99);
        ecs_board.reveal_cell(0, 0); // 初回クリック
        
        // 新実装のパフォーマンス測定
        let start = Instant::now();
        for _ in 0..100 {
            let _ = ecs_board.clone().reveal_cell(15, 8); // 中央付近でクリック
        }
        let ecs_time = start.elapsed();
        
        println!("Legacy implementation: {:?}", legacy_time);
        println!("ECS implementation: {:?}", ecs_time);
        println!("Performance improvement: {:.2}%", 
            (legacy_time.as_micros() as f64 - ecs_time.as_micros() as f64) / 
            legacy_time.as_micros() as f64 * 100.0);
        
        // 少なくとも20%の改善を期待
        assert!(ecs_time.as_micros() < legacy_time.as_micros() * 80 / 100);
    }
}
```

## テスト自動化

テストの自動化のために以下の仕組みを導入します：

### CIパイプラインの設定

```yaml
# .github/workflows/test.yml
name: Test

on:
  push:
    branches: [ main, develop ]
  pull_request:
    branches: [ main, develop ]

jobs:
  test:
    runs-on: ubuntu-latest
    steps:
    - uses: actions/checkout@v2
    - name: Set up Rust
      uses: actions-rs/toolchain@v1
      with:
        toolchain: stable
        override: true
    
    - name: Cache dependencies
      uses: actions/cache@v2
      with:
        path: |
          ~/.cargo/registry
          ~/.cargo/git
          target
        key: ${{ runner.os }}-cargo-${{ hashFiles('**/Cargo.lock') }}
    
    - name: Run unit tests
      run: cargo test --lib
    
    - name: Run integration tests
      run: cargo test --test integration
    
    - name: Run performance tests
      run: cargo bench
```

### テストカバレッジの測定

```yaml
# .github/workflows/coverage.yml
name: Coverage

on:
  push:
    branches: [ main ]

jobs:
  coverage:
    runs-on: ubuntu-latest
    steps:
    - uses: actions/checkout@v2
    - name: Set up Rust
      uses: actions-rs/toolchain@v1
      with:
        toolchain: stable
        override: true
    
    - name: Install tarpaulin
      run: cargo install cargo-tarpaulin
    
    - name: Generate coverage report
      run: cargo tarpaulin --out Xml
    
    - name: Upload coverage to Codecov
      uses: codecov/codecov-action@v1
```

## テスト優先順位付け

リソースの制約を考慮して、テストに優先順位を付けます：

| テストタイプ | 優先度 | 理由 |
|------------|--------|------|
| ユニットテスト（基本コンポーネント） | 最高 | 基盤となるコードの正確性を保証 |
| 統合テスト（システム連携） | 高 | システム間の相互作用の正確性を保証 |
| エンドツーエンドテスト（基本フロー） | 高 | ユーザー体験の正確性を保証 |
| パフォーマンステスト | 中 | 改善の効果を検証 |
| エッジケーステスト | 中 | 特殊条件での堅牢性を検証 |
| UIテスト | 低 | ボードロジック自体には直接関連しない |
| A/Bテスト | 低 | 最終段階で実施 |

## テスト環境と継続的テスト

各開発フェーズにおけるテスト環境と方法を以下のように設定します：

### 開発環境

- 単体テストと統合テストを常に実行
- `cargo test`コマンドで全テストを実行可能
- VSCodeの統合によるテスト実行と結果表示

### ステージング環境

- すべてのテストタイプを実行
- パフォーマンス測定と比較
- A/Bテストの準備と検証

### 本番環境

- カナリアリリースによる段階的な展開
- パフォーマンス監視
- ユーザーフィードバックの収集

## テスト成果物とドキュメント

テスト活動から以下の成果物を作成します：

1. テストレポート：テスト結果と発見された問題の要約
2. カバレッジレポート：コードカバレッジの詳細
3. パフォーマンス分析：既存実装と新実装の比較
4. 回帰テストスイート：将来の変更に対するセーフティネット

## まとめ

このテスト計画に従うことで、ボードロジックのECSへの移行が正確かつ効率的に行われることを保証します。フェーズごとに十分なテストを実施することで、バグの早期発見とパフォーマンス向上の検証を実現します。
