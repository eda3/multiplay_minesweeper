# ボードロジックをシステムへ移行 - 必要なシステムの特定

最終更新日: 2025年4月5日

## システムの特定と責任分離

現在の`board.rs`のロジックを分析した結果、以下のシステムに分割することが適切だと判断されました。各システムは単一の責任を持ち、ECSパターンに従って実装します。

### 1. BoardInitSystem

**責任**:
- ボードの初期化
- セルエンティティの生成
- 地雷の配置
- 周囲の地雷数の計算

**入力リソース**:
- BoardConfigResource (読み取り)

**出力リソース/コンポーネント**:
- BoardStateResource (書き込み)
- CellStateComponent (作成)
- CellContentComponent (作成)
- GridPositionComponent (作成)

**実行タイミング**:
- ゲーム開始時
- リセット時

### 2. CellRevealSystem

**責任**:
- セルの公開ロジック処理
- 連鎖的な空白セルの公開処理
- 地雷セルの公開（ゲームオーバー）判定

**入力**:
- プレイヤーのマウスクリック入力
- CellContentComponent (読み取り)
- GridPositionComponent (読み取り)

**出力**:
- CellStateComponent (書き込み)
- BoardStateResource (書き込み - 残りセル数の更新)
- GameStateResource (書き込み - ゲームオーバー状態の設定)

**実行タイミング**:
- プレイヤーのセルクリック時

### 3. FlagToggleSystem

**責任**:
- フラグ操作の処理
- フラグカウントの更新

**入力**:
- プレイヤーの右クリック入力
- GridPositionComponent (読み取り)
- CellStateComponent (読み取り)

**出力**:
- CellStateComponent (書き込み)
- BoardStateResource (書き込み - フラグカウントの更新)

**実行タイミング**:
- プレイヤーのセル右クリック時

### 4. WinConditionSystem

**責任**:
- 勝利条件のチェック
- ゲーム終了の検出と通知

**入力**:
- BoardStateResource (読み取り - 残りセル数)
- GameStateResource (読み取り - ゲーム状態)

**出力**:
- GameStateResource (書き込み - 勝利状態の設定)
- EventQueueResource (書き込み - 勝利イベントの発行)

**実行タイミング**:
- セル公開/フラグ操作の後
- 各フレームで定期的にチェック

### 5. BoardStateSystem

**責任**:
- ボード全体の状態管理
- ゲーム進行の追跡
- 統計情報の収集

**入力**:
- 他のシステムからの状態変更通知
- TimeResource (読み取り - 経過時間)

**出力**:
- BoardStateResource (書き込み - 状態更新)
- UIリソース (書き込み - 表示情報の更新)

**実行タイミング**:
- 各フレームの更新時
- 状態変更イベント発生時

## システム間の依存関係

```
BoardInitSystem → CellRevealSystem → WinConditionSystem
                → FlagToggleSystem → WinConditionSystem
                                   → BoardStateSystem
```

この依存関係に基づいて、システムの実行順序を設定する必要があります。特に、WinConditionSystemはCellRevealSystemとFlagToggleSystemの後に実行される必要があります。

## メッセージング/イベント

システム間の疎結合を維持するために、以下のイベントを定義します：

1. **CellRevealedEvent**: セルが公開されたときに発行
2. **FlagToggledEvent**: フラグが設定/解除されたときに発行
3. **GameOverEvent**: 地雷が公開されたときに発行
4. **GameWonEvent**: 勝利条件が満たされたときに発行

これらのイベントは`EventQueueResource`を通じてシステム間で通信されます。
